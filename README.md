# AI-business-factory

AI Business Factory — Starter Edition
A mobile-friendly, single-file dashboard prototype.
What works now
Business portfolio: add, search, and delete businesses
Idea lab: add starter business concepts to the portfolio
Lead manager: save and organize leads
Revenue center: manually record income and expenses
Agent task queue: create tasks and update their status
Dashboard metrics and activity feed
Browser local storage persistence
Run it
Open index.html in a browser, or publish this repository with GitHub Pages.
Publish with GitHub Pages
Create a new public or private repository on GitHub.
Upload index.html and README.md to the repository root.
In the repository, open Settings → Pages.
Under Build and deployment, choose Deploy from a branch.
Select the main branch and / (root), then Save.
Wait for GitHub Pages to publish the site.
Important limitations
This is the working front-end starter, not an autonomous AI operator. It does not yet connect to an AI API, discover leads on its own, send marketing, publish generated websites/apps, process payments, or securely sync data between devices. Data is stored in the current browser only. Never put private API keys in this public front-end. The next development stage is a secure backend and AI integration.
